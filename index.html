Development status

The publishing integration is in development. This website provides project information and policies. It does not currently offer TikTok sign-in, accept video uploads, or publish videos. TikTok API access and public publishing have not been approved or verified.

Planned workflow

Prepare a poetry video, review its text and caption, connect an authorized account, and choose the content and available publishing options before sharing. Features will depend on platform approval and supported permissions.
